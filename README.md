### REST API

[Foodgram](https://github.com/Rufina007/foodgram): сервис рецептов. Пользователи публикуют рецепты с фото, тегами и ингредиентами, добавляют чужие рецепты в избранное, подписываются на авторов и получают короткую ссылку на рецепт. Список покупок суммирует ингредиенты из нескольких рецептов и скачивается файлом. Проект упакован в контейнеры, GitHub Actions проверяет код, собирает образы и разворачивает их на сервере.
Стек: Python, Django, Django REST Framework, Djoser, PostgreSQL, Docker, Nginx, GitHub Actions.

[YaMDb](https://github.com/Rufina007/api-yamdb): API платформы отзывов на фильмы, книги и музыку. Произведения делятся на категории и жанры, пользователи оставляют отзывы с оценкой от 1 до 10, из оценок считается рейтинг. Регистрация идёт через код подтверждения на почту, после него выдаётся JWT-токен. Есть три роли: пользователь, модератор и администратор. Командный проект, нас было трое. Моя часть: модели отзывов и комментариев, права доступа, сериализаторы, вьюсеты и маршруты для отзывов, комментариев, произведений, категорий и жанров, расчёт рейтинга, фильтрация произведений, запрет повторного отзыва и загрузка данных из CSV.
Стек: Python, Django, Django REST Framework, Simple JWT, SQLite, pytest.

[API Yatube](https://github.com/Rufina007/api-final-yatube): REST API для соцсети. Можно публиковать посты, комментировать их, объединять посты в сообщества и подписываться на авторов. Вход по JWT-токену, редактировать и удалять запись может только её автор, есть пагинация и поиск по подпискам.
Стек: Python, Django, Django REST Framework, Simple JWT.

### Развёртывание проектов

[Kittygram](https://github.com/Rufina007/kittygram_final): сервис для публикации фотографий котиков с их достижениями. Основная задача здесь была в развёртывании: готовое приложение (Django и React) упаковано в контейнеры, для разработки и для сервера настроены отдельные compose-файлы, секреты вынесены в `.env`, SQLite заменена на PostgreSQL. GitHub Actions запускает тесты, собирает три образа, публикует их в Docker Hub и разворачивает проект на сервере по SSH. Если тесты не прошли, на сервер ничего не попадает.
Стек: Python, Django, Django REST Framework, PostgreSQL, Docker, Nginx, GitHub Actions.

### Flask

[YaCut](https://github.com/Rufina007/async-yacut): сервис коротких ссылок. Короткий идентификатор создаётся автоматически или вводится вручную, по нему происходит переход на длинную ссылку. Есть API для других сервисов: создать ссылку и получить длинную по короткой, ошибки приходят в JSON. Ещё сервис умеет загружать несколько файлов на Яндекс Диск одновременно и выдаёт короткую ссылку на каждый.
Стек: Python, Flask, Flask-SQLAlchemy, Alembic, aiohttp, API Яндекс Диска.

### Тестирование

[Тесты Django-проектов](https://github.com/Rufina007/django-testing): тесты для двух приложений, новостного сайта и сервиса заметок. Проверяется доступность страниц для разных пользователей, редиректы, сортировка новостей и комментариев, права на редактирование и удаление, фильтр запрещённых слов и создание slug. Одни и те же проверки написаны на pytest и на unittest.
Стек: Python, pytest, pytest-django, unittest.

### Боты и игры

[Homework Bot](https://github.com/Rufina007/homework-bot): Telegram-бот, который раз в 10 минут проверяет статус домашней работы в API Практикума и пишет, когда он меняется: работу взяли на проверку, приняли или вернули с замечаниями. При запуске бот проверяет, что заданы все токены. Все события и ошибки пишутся в лог, об одной и той же ошибке бот сообщает один раз.
Стек: Python, pyTelegramBotAPI, requests, logging.

[The Snake](https://github.com/Rufina007/the_snake): классическая «Змейка». Змейка управляется стрелками, ест яблоки и растёт, а при столкновении с собой игра начинается заново. Код разбит на классы: общий класс игровых объектов, от него наследуются змейка и яблоко.
Стек: Python, Pygame.
